**Deidril's Starfinder 1 PDF Import v7.30**
*For Foundry V14 only and Starfinder 14.0.2+*

**Fulfilling Foundry's AI Policy**

I was previously using AI-generated images for artwork and tokens when neither the Alien Archives nor the PDFs provided suitable images.

To comply with Foundry's AI policy and allow the module to still be registered in Foundry's module registry, I have made the following changes:

- Removed all AI-generated images from the module.
- Added an import option to use an external art-mapping module.

I have moved my AI-generated images into a separate, very simple module:

https://github.com/deidril/helyx-sf-ai-resources

Anyone can fork or duplicate this module to create their own art mappings for my imports. This also allows others to create alternative art packs, including paid modules featuring hand-drawn artwork, if they wish.

With this release, the SFRPG Import Module complies with Foundry's AI policy.

**Deidril's Starfinder 1 PDF Import v7.29**

*Pour Foundry V14 seulement et Starfinder 14.0.2+*

**Respect de la politique de Foundry concernant l’IA**

J’utilisais auparavant des images générées par IA pour les illustrations et les tokens lorsque ni les Alien Archives ni les PDF ne fournissaient d’images adaptées.

Afin de respecter la politique de Foundry concernant l’IA et de conserver mon module dans le registre des modules de Foundry, j’ai effectué les changements suivants :

- Suppression de toutes les images générées par IA du module.
- Ajout d'une option lors de l’import permettant d’utiliser un module externe de correspondance des illustrations (art mapping).

J’ai déplacé mes images générées par IA dans un module séparé, très simple :

https://github.com/deidril/helyx-sf-ai-resources

N’importe qui peut forker ou dupliquer ce module afin de créer ses propres correspondances d’illustrations pour mes imports. Cela permet également à d’autres personnes de créer des packs d’illustrations alternatifs, y compris des modules payants contenant des illustrations dessinées à la main, si elles le souhaitent.

Avec cette version, le SFRPG Import Module est conforme à la politique de Foundry concernant l’utilisation de l’IA.
